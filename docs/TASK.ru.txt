ЗАДАЧА: DUNE 2000 PS1 / SLUS-00973 — NATIVE PC BASELINE

Цель проекта
============

Нужно исследовать, дизассемблировать / декомпилировать / статически рекомпилировать
оригинальную PlayStation 1 версию Dune 2000 и попытаться получить НАТИВНО
запускаемую версию для Windows x64.

Исходная игра:

Dune 2000
PlayStation / NTSC-U
Serial: SLUS-00973
Исходный образ SHA-256:

94e0800ef92cfe9de3bd44cdbd8e0a85d878bded0fcfbde0cf373b8e34eac711

Это тот же исходный Vector image, который уже использовался в предыдущем
исследовании PS1-миссий.

ВАЖНО:

Это НЕ задача на модификацию игры.

Это НЕ ремейк.

Это НЕ перенос Dune 2000 PC.

Это НЕ OpenRA.

Это НЕ новый движок на Unity / Godot / Unreal.

На данном этапе необходимо максимально точно сохранить поведение именно
Dune 2000 для PlayStation.

Конечная цель текущей стадии:

Dune 2000 PS1
        ↓
оригинальный MIPS game code
        ↓
recompilation / recovered code
        ↓
native Windows executable
        ↓
игра визуально и логически ведёт себя как оригинальная PS1-версия

Но обязательно объяснить причину.


============================================================
6. ЧТО СЧИТАЕТСЯ "NATIVE"
============================================================

Запуск DuckStation внутри программы НЕ считается native port.

Запуск полноценного PS1 emulator core с оригинальным EXE без преобразования
также НЕ является конечной целью.

Допустим transitional runtime, реализующий PS1 API / hardware abstraction.

Например:

recompiled MIPS code
        ↓
PS1 compatibility runtime
        ↓
SDL/OpenGL/audio/filesystem
        ↓
Windows

Это приемлемо.

То есть игровой код должен исполняться как host/native compiled code,
а не интерпретироваться полноценным PS1 CPU emulator.

13. CD / FILESYSTEM
============================================================

Не делать native port зависимым навсегда от raw BIN sectors.

Но на первом этапе допустим compatibility filesystem.

Желательная архитектура:

оригинальный CD file request
        ↓
virtual PS1 filesystem
        ↓
локально extracted assets

Создать importer:

dune2000-import <user-owned BIN/CUE>

Он:

1. проверяет SHA-256;
2. определяет SLUS-00973;
3. извлекает необходимые assets локально;
4. складывает их в generated/assets;
5. ничего copyrighted не коммитит в repository.

Native executable затем читает local imported assets.

Если для раннего proof-of-concept проще читать BIN напрямую — допустимо,
но зафиксировать это как временное решение.
